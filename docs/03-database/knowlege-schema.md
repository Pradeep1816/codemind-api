> is retained only as historical design context.

This was the original knowledge-layer concept for CodeMind.

The previous schema (code-intelligence-schema.md) understands:

"What exists in the code?"

The Knowledge Schema understands:

"What does this code mean?"

This layer converts technical information into reusable software knowledge.

## Document Information

# 1. Overview


The Knowledge Schema stores information generated by CodeMind's
analysis engine.


It represents the understanding of a software system.



Examples:



Code:



if(paymentFailed){
createCredit();
}




Knowledge:




Business Rule:

When payment fails, the system creates customer credit.




The Knowledge layer connects:



Code

Architecture

Business Rules

Documentation




# 2. Responsibilities


The Knowledge Schema manages:



- System understanding
- Module explanations
- Business rules
- Architecture decisions
- Code summaries
- Technical insights
- Evidence tracking
- Confidence scoring
