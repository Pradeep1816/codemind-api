# ADR-001: Use NestJS

## Status

Accepted

## Context

CodeMind requires a scalable backend with modular architecture.

## Decision

Use NestJS with TypeScript.

## Reasons

- Strong module system
- Dependency injection
- Enterprise-ready architecture
- Good TypeScript ecosystem

## Consequences

Positive:

- Maintainable codebase
- Easy testing
- Clear boundaries

Negative:

- More structure compared to Express
