## Repository

A software project source code collection managed by a version control system.


## Indexing

The process of scanning source code and extracting structured information.


## Parser

A component that converts source code into an understandable structure.


## AST

Abstract Syntax Tree.

A structured representation of source code.


Example:


Function

|

Parameters

|

Statements



## Knowledge Graph

A graph representation of relationships between software concepts.


Example:


Student

|

Enrollment

|

Invoice



## Embedding

A numerical representation of text or code used for semantic search.


## Vector Database

A database optimized for storing and searching embeddings.


## Business Rule

A rule describing system behaviour from a business perspective.


Example:

"Cancelled lessons cannot be invoiced."


## Call Graph

A representation showing which functions call other functions.


## Context Builder

A component that prepares relevant information for AI models.


## MCP

Model Context Protocol.

A standard protocol allowing AI agents to access external knowledge sources.


## AI Agent

A software system capable of reasoning and performing tasks using AI models.
